# Concurso Agrinho 2026 - Programação Web

## Informações do Projeto
- **Tema:** Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.
- **Subcategoria:** 3 - Programação Front-End (HTML, CSS e JavaScript).

## Objetivo do Site
Este site tem como propósito conscientizar o usuário sobre a importância da tecnologia aliada à preservação ecológica no agronegócio. Ele oferece uma interface limpa, acessível em dispositivos móveis e conta com uma calculadora interativa capaz de mensurar o impacto positivo de práticas agrícolas sustentáveis na preservação florestal.

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo e formulários de dados.
- **CSS3:** Estilização baseada em variáveis estruturadas e responsividade nativa através de Media Queries.
- **JavaScript (Vanilla JS):** Manipulação de elementos estruturais do DOM, gestão de eventos interativos do usuário e processamento lógico local.

## Instruções de Uso
1. Abra o arquivo `index.html` em qualquer navegador web moderno.
2. Utilize o botão "Alternar Modo Escuro" no topo da página para ajustar o contraste visual.
3. No formulário inferior, digite seu nome e simule a quantidade de hectares de cultivo.
4. Clique em "Calcular Sustentabilidade" para ver o resultado gerado dinamicamente na tela.
